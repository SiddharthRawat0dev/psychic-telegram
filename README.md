# i&Beyond — single-page storefront preview

Open `index.html` or publish this folder with GitHub Pages. The entire customer-facing experience is now one page: home, shop catalogue, pre-owned, repairs, services, workspace and store location. `shop.html` is a tiny redirect for old bookmarks.

Included catalogue data is a snapshot from 21 October 2026. Product stock is not live. The preview bag does not place orders; customers must contact the store to confirm availability.

Photos use the original iandbeyond.com image URLs where available. If a remote image fails, the interface tries the next gallery image and then shows a clear fallback.
