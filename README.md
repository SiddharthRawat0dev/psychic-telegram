# i&Beyond website design

Upload index.html, style.css, app.js, catalogue.js, and the assets folder to the root of your GitHub repository. Keep the assets folder intact. Enable GitHub Pages from main / root.

This is the complete front-end project with separate source files and the real catalogue snapshot. Product photos load from their original public URLs on iandbeyond.com, so an internet connection and continued source availability are required. The main design images and supplied map are included locally. The preview bag does not create orders.
